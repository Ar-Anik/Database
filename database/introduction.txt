Q : What is Database ?
--> A database is an organized collection of data that can be easily accessed, managed, and updated. It is designed to store,
retrieve, and manage information efficiently for various applications. Databases are widely used in systems ranging from small
personal applications to large enterprise solutions.

# Key Features of a Database:
1. Structured Organization:
    * Data is stored in tables, records, or other structures, depending on the type of database.
    * Each table consists of rows (records) and columns (fields or attributes).

2. Data Management:
    * Databases allow users to perform operations such as adding, retrieving, updating, and deleting data.

3. Efficiency:
    * They are optimized for fast data retrieval and complex queries, ensuring performance even with large datasets.

4. Security:
    * Access controls ensure that only authorized users can view or modify the data.
    * Encryption is often used to protect sensitive data.

5. Consistency:
    * Databases enforce rules to maintain the integrity and accuracy of the stored data.

# Types of Databases:
1. Relational Databases (RDBMS):
    * Organize data into tables with relationships between them.
    * Use SQL (Structured Query Language) for managing and querying data.
    Examples: MySQL, PostgreSQL, SQLite, Microsoft SQL Server.

2. NoSQL Databases:
    * Designed for unstructured or semi-structured data.
    * Suitable for large-scale and distributed systems.
    # Types include:
        1. Document Stores: MongoDB, CouchDB.
        2. Key-Value Stores: Redis, DynamoDB.
        3. Column-Family Stores: Cassandra, HBase.
        4. Graph Databases: Neo4j.

3. In-Memory Databases:
    * Store data in memory for extremely fast read and write operations.
    Examples: Redis, Memcached.

4. Cloud Databases:
    * Hosted on cloud platforms, providing scalability and availability.
    Examples: Amazon RDS, Google BigQuery.
