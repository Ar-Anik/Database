একটি view define করার পর, সেই view-এর নামটিকে একটি সাধারণ রিলেশন বা টেবিলের নামের মতো ব্যবহার করা যায়।

Example : আগে তৈরি করা physics_fall_2009 view-টি ব্যবহার করে 'Watson' বিল্ডিংয়ে অফার করা সকল physics কোর্সের list নিচের কুয়েরির মাধ্যমে
খুঁজে বের করা সম্ভব:
    select course_id from physics_fall_2009
    where building = 'Watson';

একটি SQL কুয়েরিতে যে যে স্থানে টেবিলের নাম ব্যবহার করা সম্ভব, ঠিক সেই সব স্থানেই view-এর নাম ব্যবহার করা যায়।

view-এর কলাম বা atrribute-এর নামগুলো আলাদাভাবে উল্লেখ করে দেওয়া যায়। এটি বিশেষ করে তখন প্রয়োজন হয় যখন কুয়েরিতে কোনো aggregate function
যেমন: sum, avg etc ব্যবহার করা হয়, কারণ সেই ফাংশনগুলোর নিজস্ব কোনো কলাম নাম থাকে না।

Example : প্রতিটি department-এর সকল instructor-এর মোট বেতনের summation দেখানোর জন্য নিচের view-টি তৈরি করা যায়:
    create view departments_total_salary(dept_name, total_salary) as select dept_name, sum(salary)
    from instructor group by dept_name;

এখানে sum(salary) অংশটির কোনো নাম নেই তাই view সংজ্ঞায়িত করার সময় braket-এর ভেতর dept_name এবং total_salary নাম দুটি স্পষ্টভাবে
লিখে দেওয়া হয়েছে।

কোনো একটি নির্দিষ্ট সময়ে একটি view-তে যে ডেটা বা tuples-গুলো দেখা যায় তা হলো ওই view-টি তৈরি করার জন্য ব্যবহৃত কুয়েরিটির ফলাফল। যদি একটি
view-এর ফলাফল গণনা করে স্থায়ীভাবে store করে রাখা হতো তবে মূল টেবিল (যেমন: instructor) আপডেট করার সাথে সাথে view-এর তথ্যগুলো পুরনো
বা ভুল (out of date) হয়ে যেত। এই সমস্যা এড়াতে database system view-কে নিচের পদ্ধতিতে পরিচালনা করে:

- Database system view-এর query থেকে প্রাপ্ত ফলাফল জমা রাখে না বরং view-এর definition বা কুয়েরিটি জমা রাখে।

- যখনই কোনো কুয়েরিতে view-এর নাম ব্যবহার করা হয়, তখন সিস্টেম view-এর নামের জায়গায় আগে থেকে সংরক্ষিত কুয়েরিটি বসিয়ে দেয় (replace করে)।

- এর ফলে প্রতিবার কুয়েরি চালানোর সময় view-টি নতুন করে compute করা হয় এবং সব সময় updated তথ্য পাওয়া যায়।

একটি view ব্যবহার করে নতুন আরেকটি view তৈরি করা সম্ভব। একে Nested Views বলা হয়। Example :
আগে তৈরি করা physics_fall_2009 view-টি ব্যবহার করে 'Watson' বিল্ডিংয়ের জন্য নতুন একটি view physics_fall_2009_watson তৈরি করা যায়:
    create view physics_fall_2009_watson as
    select course_id, room_number
    from physics_fall_2009
    where building = 'Watson';

এখানে physics_fall_2009_watson ভিউটি অন্য একটি ভিউ-এর ওপর ভিত্তি করে তৈরি। এটি আসলে নিচের জটিল কুয়েরিটির equivalent:
create view physics_fall_2009_watson as
(select course_id, room_number
 from (select course.course_id, building, room_number
       from course, section
       where course.course_id = section.course_id
         and course.dept_name = 'Physics'
         and section.semester = 'Fall'
         and section.year = '2009')
 where building= 'Watson');
