1. Record Pointer (Data Pointer)
A record pointer points to the actual data record (row/tuple) in the table or file. Usually appears in the
leaf nodes of the B+ Tree. Each key in the leaf node has a record pointer attached to it.

# Example (Leaf node): | 20 → Record(Bob) | 30 → Record(Charlie) |
Key 20 has a record pointer → full row for Bob.
Key 30 has a record pointer → full row for Charlie.


# Example :
| StudentID | Name    | Marks |
| --------- | ------- | ----- |
| 10        | Alice   | 85    |
| 20        | Bob     | 90    |
| 30        | Charlie | 75    |
| 40        | David   | 95    |
-------------------------------

-> Root Node (Internal) : | P0 | 20 | P1 | 40 | P2 |
Keys = 20, 40
Block pointers = P0, P1, P2

-> Child Nodes (Leaves with Record Pointers)
1. P0 (left child): | 10 → Record(Alice) |
2. P1 (middle child): | 20 → Record(Bob) | 30 → Record(Charlie) |
3. P2 (right child): | 40 → Record(David) |

-> Search Example: Find StudentID = 30
1. Start at root: | P0 | 20 | P1 | 40 | P2 |
    * 30 > 20 and 30 < 40 → follow block pointer P1.
2. Go to child node (P1): | 20 → Record(Bob) | 30 → Record(Charlie) |
    * Found key = 30 → follow record pointer → get full row {30, Charlie, 75}.
