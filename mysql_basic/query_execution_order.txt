-> MySQL Query Execution Order (Logical Evaluation Order):
1. FROM
    Identifies the source tables and performs JOINs, ON conditions, and generates a working data set (intermediate result).
2. WHERE
    Filters rows from the intermediate result created by FROM. Only rows satisfying the condition remain.
3. GROUP BY
    Groups remaining rows by one or more columns.

4. Aggregate functions (SUM, COUNT, AVG, etc.) are calculated.

5. HAVING
    Filters the grouped results (not individual rows). It applies conditions on aggregate functions like COUNT, SUM, etc.
6. SELECT
    Chooses and computes the final columns to be returned (including aggregate functions, aliases, expressions).
7. ORDER BY
    Sorts the final result rows. We can order by columns, aliases, or expressions.
8. LIMIT
    Restricts the number of rows returned to the client.

-> The Sequence :
    FROM → WHERE → GROUP BY → Aggregate Functions → HAVING → SELECT → ORDER BY → LIMIT

-> Special Note :
    1. FROM includes joins, subqueries, and table aliases.
    2. WHERE only works on individual rows, before grouping.
    3. HAVING works after grouping, so it can filter on aggregated values.
    4. SELECT can use aliases defined in the same clause, but not in WHERE.
    5. ORDER BY can use column names, aliases, or position index (e.g., ORDER BY 2).
