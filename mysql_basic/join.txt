-> A JOIN is used to combine rows from two or more tables based on a related column between them — typically a foreign key.

In mysql 4 type of join exist :
    1. INNER JOIN (or just JOIN)
    2. LEFT JOIN (or LEFT OUTER JOIN)
    3. RIGHT JOIN (or RIGHT OUTER JOIN)
    4. CROSS JOIN

-> Basic Traversal Logic: In a Mysql JOIN, the database engine compares each row from the left table with rows from the
right table based on the ON condition. If matches are found, a combined row is created in the result. If multiple matches
are found, multiple result rows are generated. If no match is found:
    1. INNER JOIN : Selects records that have matching values in both tables.

    2. LEFT JOIN : The LEFT JOIN keyword returns all records from the left table, and the matching records (if any)
       from the right table. The LEFT JOIN keyword returns all records from the left table, even if there are
       no matches in the right table.

    3. RIGHT JOIN : The RIGHT JOIN keyword returns all records from the right table, and the matching records (if
       any) from the left table. The RIGHT JOIN keyword returns all records from the right table, even if there are
       no matches in the left table.

    4. CROSS JOIN : CROSS JOIN keyword returns all records from both tables. If we add a WHERE clause, the CROSS JOIN
       will produce the same result as the INNER JOIN clause.

-> Join Think of it as:
  for each row in Table_A:
    for each row in Table_B:
        if join_condition matches:
            add combined row to result

This nested traversal is what gives basic joins their O(m × n) time complexity in the worst case.
