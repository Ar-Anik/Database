-> Foreign keys can reference the same table, useful for hierarchical structures (org charts, category trees, threaded comments).

CREATE TABLE employees (
    `emp_id` INT AUTO_INCREMENT PRIMARY KEY,
    `emp_name` VARCHAR(100),
    `manager_id` INT,
    FOREIGN KEY (manager_id) REFERENCES employees(emp_id) ON DELETE SET NULL
);

- Deleting a manager sets subordinates’ manager_id to NULL.
- Prevents broken hierarchies.
